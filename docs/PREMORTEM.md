# Project Premortem

Assume the project failed after 4 weeks. Why?

## Failure Modes

1. I spent too much time comparing tools instead of building.
2. I tried to analyze too many companies.
3. I tried to build an AI ESG platform instead of one focused case study.
4. I kept asking about APIs before downloading and reading the reports.
5. I did not define what counts as greenwashing.
6. I had no weekly output.
7. I used Codex to overbuild instead of shipping.
8. I trusted AI extraction without manual validation.
9. I ignored finance relevance and produced only generic ESG summaries.
10. I did not turn the project into a clear internship story.

## Prevention Rules

1. Only two companies first: TSMC and ASE.
2. Only three claim categories first: emissions, renewable energy, supply chain.
3. No autonomous agent system in Week 1.
4. No paid API until 10 claims are manually extracted.
5. Every week must produce a visible artifact.
6. Codex can write code, but I define the research logic.
7. Final output is a GitHub repo, dashboard, and short findings report.
8. Every extracted claim must link back to source page/report section.
9. Scores must be explainable, not black-box.
10. The final narrative must answer: "How does this help an ESG/sustainable finance team?"
